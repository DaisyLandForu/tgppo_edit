# 原评分头重新初始化对照

日期：2026-11-02（北京时间）。[授权](AUTHORIZATION.md)依据用户对上一阶段的明确验收。[方案](protocol.json)在运行前冻结。**本轮已完成并停止，等待验收。**

**结论：重新初始化原 TreeGate 评分头没有恢复预定的条件学习响应。两个来源种子 × 两个固定初始化，四组各完成 20 步，surrogate 均未改善，训练和监测 TV 中位数均为 0。结合上一轮同表示线性头能小幅响应，证据更支持“原评分头参数化在当前冻结表示和优化设置下难以传递候选学习信号”；不支持把重置 ep100 中间层作为现成修复，也尚未唯一定位 LN2。**

## 1. 做了什么

- 复用原先固定的 s11/s22 ep100 BiMatching 与树表示缓存、256 个更新状态、164 个监测状态及真实完整轨迹优势；没有新采样、重算 GAE 或使用测试集。
- 使用同一个原版 TreeGate 类、相同层数/宽度/门控/LayerNorm。以初始化种子 101/202 构造全新评分头，检查 LayerNorm 的 gamma=1、beta=0，再将最终标量读出的权重和偏置归零。
- 同一初始化种子在两份来源表示上使用完全相同的初始参数。两初始化不是两个额外来源训练种子；本轮仍只有两个来源模型。
- 两组初始策略均匀且与原保存行为概率匹配；fresh Adam、lr=0.00024、clip=0.16、entropy=0.003、梯度上限 0.5、逻辑 batch256 / micro16 均复用上一轮实现。
- 四组在本地单线程串行执行，每组固定 20 步；原头/线性头历史参照直接复用，没有重跑。完整上游 Actor 与 Critic 均未更新，原基线与来源文件未修改。

这是冻结表示上的有限批次条件拟合，不是完整 Actor 从头训练，也不是原 B0 续训。归零读出会使第一步前级梯度为零，这与上一轮配对初始化相同；不能从该初始化下的短拟合推断任意初始化和长期训练都失败。

## 2. 结果：0/4 达到运行前筛查

预定筛查：末步 surrogate loss 至少降低 1e-6，且训练 TV 中位数 >1e-6。两项都满足才称有可测条件响应；不是分支正确或 PDI 改善门槛。

| 来源种子 | 头初始化种子 | 更新步数 | surrogate 变化 | 训练 TV 中位数 | 监测 TV 中位数 / 最大值 | 达到筛查 |
|---|---|---:|---:|---:|---:|---|
| 11 | 101 | 20 | 0 | 0 | 0 / 7.45e-8 | 否 |
| 11 | 202 | 20 | 0 | 0 | 0 / 0 | 否 |
| 22 | 101 | 20 | 0 | 0 | 0 / 0 | 否 |
| 22 | 202 | 20 | 0 | 0 | 0 / 0 | 否 |

**E1：所有四组均未达到筛查。** s11/init101 在个别监测状态上仍测到最大约 7.45e-8 的概率变化，不能笼统写成四组所有输出严格不变；四组末步监测状态超过 TV=1e-6 的数量均为 0/164。全部曲线和状态级指标保留，不只报告末步。

参照上一轮：保留 ep100 中间层的原头，两来源 surrogate 变化均为 0；线性头分别为 −1.483e-5 / −9.704e-5，训练 TV 中位数为 5.811e-5 / 4.976e-4。故本轮结果是**重新初始化后仍弱**，不是“所有头都无可拟合信号”。线性头改善仍很小，不是已验证的求解修复。

每组 checkpoint 与 34 个参数张量的 Adam step 均为 20，无未提交 inflight。总计实际执行 **80 个评分头更新步**，不是只做前向。梯度远低于裁剪上限；候选相对分数响应远小于共同平移，与 softmax 概率弱响应一致。以上仍是描述证据，不为各层分配性能损失份额。

## 4. 对瓶颈判断的更新

| 判断 | 证据等级与边界 |
|---|---|
| 只需重置 ep100 原头中间层即可恢复响应 | **E4：本轮不支持。** 两初始化、两来源均未恢复；不等于历史中间层权重从无影响 |
| 原头结构/参数化与当前表示组合存在优化困难 | **E1 支持增强。** 已训练原头与重置原头均弱，同表示线性头有小幅响应；限定当前零读出初始化、优化设置与 20 步预算 |
| 唯一问题就是 LN2、树门控或某一层 | **E3：未唯一分离。** 重置未替换任何结构，线性对照则替换整个头；旧 LN2 冻结干预也未恢复明显偏好 |
| 原作者正式模型必然失败或论文结论错误 | **E3：没有这项证据。** 使用的是本地 ep100 表示和缩预算协议，未验证作者正式权重 |
| 应增加随机初始化搜索、延长到完整训练或上 V100 | **E4：当前不支持直接投入。** 预定四组已完成，结果不因弱而自动扩预算 |

当前优先处理 **Actor 评分头的条件学习响应**。上游候选差异压缩、优势质量及分支价值标签缺失仍存在；本轮没有替它们排除责任。没有产生新的 PDI、证明率或未见实例泛化证据。

## 5. 下一阶段建议（未实施）

不再重复更换初始化或加长同一批重放。建议只做一次**末端窄压缩链的结构对照**：保留原头前五个评分层和原树门控，在宽 8 的表示后接单个 Linear(8,1)，替换原有的 8→4→2→1 尾部；最终读出仍归零。前五层与门控从本轮 initial.pt 直接配对复用，避免再次混入初始化差异。

这检验末端窄压缩链整体是否限制响应，不把它称为只修改 LN2，也不宣称参数匹配。可继续采用相同四对来源/初始化、20 步、单线程本地总上限 180 秒；复用当前原头作参照。若固定 surrogate 与训练 TV 仍不过既定筛查，结束该末端头修补路线，转而审计上游表示/优势信号；即使通过，也只完成条件学习验证，不能自动启动线上采样或完整训练。

本轮没有实现该结构或执行该方案。真实分支质量与求解收益仍需另立小预算标签/求解验证。
