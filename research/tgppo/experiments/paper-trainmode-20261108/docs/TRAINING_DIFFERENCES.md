# 训练差异对最终效果的影响与本轮调整

2026-11-08。以下区分源码机制、已观察事实和未验证的效果；没有证据量化某个差异造成多少PDI变化。

| 差异 | 可能影响最终结果的机制 | 本轮处理 |
|---|---|---|
| Actor更新eval／train | 改变dropout正则、梯度及PPO比值分布；影响可能实质性，方向和幅度未知 | 改为train；B0训练dropout恢复.05；原网络文件不改 |
| GAE、done与bootstrap | 直接改变Actor优势和Critic目标，可能改变梯度大小甚至方向 | 保留标准分episodeGAE和正确边界；单元测试手算终止／截断目标 |
| 每episode／多轨迹合并 | 改变策略刷新频率、优化步数及优势归一化范围；影响通常不可忽略 | 按正文逐完整episode后3epoch；当前旧paper-aligned本来已如此，本次无需改回 |
| 120／3600秒、20／25实例、solver0–2／0–4 | 改变任务、数据分布、训练覆盖和奖励归一化；不能只视为速度差 | 当前旧paper-aligned已对齐，新包继续500／3600／25×5，不重用短预算分母 |
| Adam／AdamW及学习率 | 改变优化轨迹和权重衰减，可能影响学习 | 当前旧paper-aligned已是AdamW，本轮继续正文参数 |
| B0／MLP模型结构 | 改变表达能力、条件响应、推理成本和随机数消耗，是方法因素 | 保留原B0及既定MLP；新流程三组统一，不把公共修复算MLP增量 |
| BC初始化 | 改变起始策略和探索树分布，既可能改善也可能引入尾部风险 | 仅MLP＋BC有；合法专家数据和内部选择规则保持 |
| CPU／GPU、微批 | 同一目标不等于同一数值轨迹；训练dropout下微批还有不同掩码组织 | 设备显式、同轮一致；加权微批不额外增加AdamW步，不默称逐位等价 |
| 初始化、动作、solver随机流 | 改变访问的树与后续训练样本，结果可能跨种子变化 | 同种子初始Critic与BC前MLP相同；配对日程和动作流；保留两训练种子 |
| 特征、cutoff及solver设置 | 若改变会改变策略输入、搜索树和任务目标，属于重要混杂 | 本轮不改getter公式、SCIP6.0.1、启发式关闭和已知最优cutoff |
| 状态／日志／checkpoint保存 | 正确实现时不改变数学目标；计时仍有I/O成本 | 原子pending/latest、模型／优化器／RNG恢复检查与累计预算继续保留 |

`eval()`不会关闭梯度，旧版本不是因此没有调用反向。恢复train模式也不保证修复已观察到的候选评分弱响应：初始化时和冻结权重切换train模式的少量检查也曾近均匀。需要看新训练的实际输出变化及最终求解表现。

Actor的train/eval细节来自作者公开代码，正文仅给dropout超参数；不能说正文已经明确披露了全部模式关系。标准GAE是本次用户选择，不能说它逐字复刻了公开代码里的额外遮罩。

## 新日志如何判断

- `initial_ratio_max_error`：第一次逻辑batch、任何优化步前，以eval核对采样旧概率，应小于1e-4；不一致仍立即失败。
- `initial_train_ratio_max_error`／`initial_dropout_clip_fraction`：同样在第一次优化步前，但使用train模式，反映dropout带来的概率扰动；它们可以非零，不代表参数已经学到。
- `clip_fraction`：整个更新的train比值截断比例，包含dropout噪声，不能单看这一项判定有效学习。
- `deployment_tv_before_after_mean`：第一次微批至多8状态，在eval下比较整次PPO更新前后分布；另记距均匀TV、argmax变化。面板很小且来自训练，不是性能验证或独立开发集。
- 最终收益仍看固定权重相对relpscost的PDI、证明率、节点和部署成本，不能用上述日志替代求解评测。

若要单独量化dropout改动，需在同设备、同数据与相同训练预算下比较，不能把旧CUDA训练与新CPU训练的所有差异都归因于模式。当前新包回答正文设置下三种方法的公平对照；没有预先承诺B0会恢复强学习或任何方案会获益。
