# 对照定义与解释边界

日期：2026-11-02。上轮单步重放已获用户验收。本轮用户请求提供可并行的实验脚本/配置，并明确选择“离线评分头对照”；由用户提交真实 Custom 作业，本地只准备输入和验证入口。

## 为什么比较这两组

已测共同衰减范围是 BiMatching→logits。只处理 LN2 的冻结权重干预没有恢复明显偏好，因此本轮首先测试**整个现有评分头是否限制了既有表示上的学习响应**，用简单线性头作诊断对照。它不预设新模型有效，也不再次把无标签激活变尖当成结论。

两组均使用同一 ep100 checkpoint 的冻结 Transformer、BiMatching、tree embedding。缓存是原 Actor 实际前向捕获的 BiMatching 输出和树向量，回放原评分头必须与原 Actor 输出逐位一致。缓存不会近似、量化或截断候选。

原头使用原 TreeGate 结构与其中间层权重；对照头为 Linear(256,1)，树向量已参与上游 BiMatching，对照头不另外引入 gate。两组最后读出均归零，头优化器均为 fresh Adam，初始分布逐候选一致；本轮没有保存并使用“某个组训练过、另一个组随机初始化”的不对称初始输出。原头中间层保留的训练历史与结构本身仍无法分离，因此结果仅针对当前训练表示/中间映射条件，不能宣布原头结构在任何初始化下都无效。

## 数据和目标

取已验收 `tgppo_20261102_ppo_replay` 的固定 batch 索引。种子11/22分别来自 3,735/5,902 条完整缓冲算出的 GAE，训练各256条。保存动作、旧行为概率及归一化优势保持原样；不伪造专家标签、不局部截断后重算 GAE。原 checkpoint 的行为分布在这些状态近均匀，统一均匀初始读出必须通过全批 ratio 最大偏差≤1e-4 检查，失败即不训练。

目标沿用 PPO clipped surrogate 加熵项，batch256、micro16，逻辑 batch 内梯度按实际微批大小加权。相同的256条数据固定重复20步，**这是有限数据条件拟合，非标准在线 PPO 训练续接**；不新增 rollout，不更新 Critic/GAE，不拿测试集做选模。

监测集为已冻结164个 train 状态、17个实例，与本轮更新轨迹不同；它只能显示对其它已见训练状态的响应。没有完整候选行动价值标签，不能评价分支排序是否正确，也不能把旧保存动作当专家最优动作。

## 记录、停止和验收

每一步记录训练 surrogate/entropy/clip、相对初始策略的 KL/TV、相对均匀 TV、去除共同平移后的 logit 变化，以及监测集同项指标。全量状态表保留实例与状态键；只按种子配对描述，两个来源训练种子不是四个独立重复。

以下任一条件停止对应作业并保留材料：非有限、版本/输入/code SHA 变化、初始策略不一致、初始 ratio 不符、训练状态平均 KL(initial||current)>0.02、达到20个头更新步、达到600秒墙时。KL=0.02和TV=1e-6只是预定工程边界，不是正确决策或求解收益阈值。

汇总要求四个作业均正常完成20步、同一代码/协议/缓存、完整step0–20及交付SHA。缺作业、早停、损坏或失败会生成 completeness.json 并非零退出，不能删除失败组后宣布完整比较。早停可作为有效的阶段性发现，但需要连同预算与缺口另行审阅，不自动补跑其它超参。

| 结果模式 | 允许的解释 |
|---|---|
| 线性头响应/固定 surrogate 拟合明显强于原头，两个种子方向一致 | 支持当前评分头映射限制给定学习信号传递；不唯一定位 LN2，不证明分支质量或 PDI 提升 |
| 两组都能响应 | 头在本轮统一初始化/fresh Adam条件下可拟合；历史动量、初始化及端到端训练耦合仍待分离 |
| 两组都弱 | 原头不是已证明的唯一原因；上游表示和优势噪声仍可能限制，停止继续叠补丁 |
| 只出现 TV 放大，没有固定目标拟合证据 | 不宣布恢复有效学习 |
| 种子方向不一致、初始检查不通过或早停 | 收窄结论，不扩展为普遍结构结论 |

无论输赢，四作业汇总交付后停止。若未来要谈求解收益，需要新的同预算在线数据/训练与真实 Actor-only 求解阶段。
