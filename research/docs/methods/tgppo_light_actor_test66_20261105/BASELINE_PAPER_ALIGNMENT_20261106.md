# 当前B0与论文TGPPO的对齐说明

核验日期：2026-11-06，北京时间。仅阅读原论文、源码、配置和已完成记录，没有训练/求解/改权重。

**当前B0是保留原Actor/Critic结构的修正实现和受控预算参照，不是已经复现论文性能的最终TGPPO。** 不能把“原网络结构”“完成当前实验闭环”“复现论文完整协议/数值”混成同一件事。

论文来源：[作者论文全文](https://arxiv.org/html/2511.12986v1)，§4.3、§5.2–5.4；同时核对本地AAAI camera-ready文本。原版训练入口`tgppo/repo/code/train.py`使用AdamW；当前入口`tgppo/experiments/light-actor-20261105/code/project/runtime.py`使用Adam。这不是论文要求的改进，也不能当成正确性修复或研究创新。

| 项目 | 论文报告 | 本轮轻量Actor对照的B0 |
|---|---|---|
| Actor主结构 | 256维、5层Transformer、8头、树交互与TreeGate评分 | 保留，Actor参数4,738,895，没有缩成轻量MLP |
| 最终训练 | 共500个完整episode | 每种子100个完整episode，两份B0各25轮有效PPO批更新 |
| 一次episode | 一个MILP求解至最优/截止，最多3600秒 | 最多120秒；超时按有限时任务终止 |
| 最终训练数据 | 全25实例×solver seeds0–4 | 20训练，另5开发；训练solver0–2 |
| 优化器 | AdamW；原版入口weight_decay=.01 | Adam，未设置AdamW权重衰减 |
| 更新组织 | 文字描述每episode后3个优化epoch | 4完整episode收集一批，满足256样本才更新，每次3epoch |
| 其他主要超参数 | actor lr .00024、critic lr .00012、clip .16、entropy .003、gamma .97、lambda .92、batch256、H3 | 数值沿用；显存微批16不改变逻辑batch256 |
| 测试 | 66实例、solver0–4、每次3600秒；33 easy按节点、33 hard按PDI，SGM/秩/实例胜率 | 同66实例、solver0/1、120秒；全体算术平均PDI、证明率、PAR-2与成本 |
| 求解器外围 | SCIP6.0.1、关闭原始启发式、已知最优cutoff | 这些关键设置沿用；不等于生产默认SCIP |

500是总训练episode数，不是每个实例500次；3个优化epoch也不是3个MILP求解episode。当前100是其episode计数的1/5，时限120是3600的1/30，但不能据此声称实际计算量或学习效果恰好相差150倍。

还存在对齐项：当前Actor rollout和PPO重算使用eval模式，名义dropout=.05但Actor有效dropout=0；Critic训练dropout=.05。论文只给dropout=.05，不能当成这些执行细节都已完全匹配。论文shared front-end的文字与原代码独立Actor/Critic的关系仍属于既有核查边界，不在本轮擅自改共享结构。

## 历史500episode实验与本轮不能混淆

项目在server6-20261022确实完成过两份B0各500episode，summary记录125／123轮有效PPO更新。其开发集按既定规则均选中episode100；同样是120秒、Adam、20训练＋5开发、4episode收集批，测试用3个solver种子。它也不是论文3600秒/AdamW的完整协议。

本轮轻量结构独立对照重新训练B0到100，使用自己的权重及新66评估；不是从旧500权重导出本轮表格。历史B0均值2407.483与本轮2708.509来自不同批次、硬件/种子等条件，不直接用其比值声称训练退化。历史证据见`tgppo/runs/server6-20261022/{training/B0-s11,training/B0-s22}/summary.json`与`stage5-results-20261023/selected_models.csv`。

## 目前能否说性能复现成功

不能声称已重现论文主要性能结论，也不能给出“达到论文性能的百分之几”。论文表3是与其他学习分支器/原生规则的实例胜率；例如PDI对TBRANT为90.62%、对relpscost为46.87%。这些不是平均PDI下降百分比，也不是证明完成率。论文并未全面超过relpscost，因此当前输给原生本身不足以证明复现错误。

当前可确认：本轮B0在120秒下平均PDI2708.509、证明率17.803%；同批原生2653.381、31.818%，B0的平均PDI高2.078%、证明率低14.015个百分点。本轮没有同协议重测TBRANT等论文学习基线；3600秒PDI与120秒PDI也不能通过乘30转换比较。

当前改进证据只适用于此共同协议：无BC的MLP相对本轮B0的部署开销、证明率及共同Actor PDI改善。它不证明已超过论文完整训练TGPPO。短预算、Adam/AdamW及更新组织各自影响多大，当前没有单变量对照，不能归咎于某一个因素，也不能保证只加到500就能恢复论文结果。

若后续要建立正式论文级改进结论，应先在独立副本冻结并对齐基线协议（优化器、更新、数据/solver覆盖、训练曲线、评测时限及统计口径），核验基线后再给改进组匹配预算。此处是后续建议，不是启动新500episode或3600秒矩阵的授权。本轮旧源码、配置、权重与报告均保留。
