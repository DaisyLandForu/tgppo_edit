# B0弱响应：直接机制与复现归因

2026-11-18。补充回答“是否按论文复现、是论文还是复现出问题”。本轮只读核对已有诊断、当前源码、论文v1及作者固定公开提交，没有新增训练/优化步/求解或修改作业。

**判断：候选差异在公开Actor评分链中被多阶段削弱，有源码、逐层测量和局部干预证据；但造成当前长期训练停留在弱响应状态的完整原因尚未确定。不能宣判论文方法必然失败，也没有证据将它解释成用户启动命令或某个超参数填错。当前属于仍未复现作者结果的基线可学性异常。**

## 1. 不是只从clip=0猜原因

当前新B0已使用采样eval、更新train及dropout0.05。在330轮快照的318次非空更新中clip均为0，部署探针距均匀TV最大2.44e-7、更新前后TV最大1.22e-7。这是新模式长期训练的记录；不能继续把旧版本Actor更新eval当成新B0仍近均匀的充分解释。探针只覆盖每轮最多8个训练状态。

历史固定状态诊断另测得：输入/embedding仍有候选差异，Transformer中逐层弱化，BiMatching后的评分链共同强收缩，最终logit近乎相同。历史PPO单步确认优化器执行、优势非零、模型参数改变，但主要logit变化是各候选共有的平移，动作概率只微变。历史实验的状态/预算/模式与当前330轮不同，不能冒充已在当前模型逐层重做过所有定位。

直接机制可解释为：

1. BiMatching将候选个体通路变为一个标量β_i乘公共树向量，再与公共聚合信息匹配，缺少原候选表示的直接残差。给定公共上下文，β_i相同的两个候选无法在该模块之后被重新区分。
2. TreeGate将256维逐步压到128/64/32/16/8/4/2/1，反复施加公共树门控。末端LayerNorm(2)在两通道差同号且远离epsilon区域时，会把不同候选压成近似相同的正负模式，进一步削弱局部差异。最终2→1是Linear，**没有LayerNorm(1)**。
3. 候选logit几乎一致，softmax便近均匀；所有logit一起平移也不会改变softmax。因此参数更新不等于决策偏好更新，概率比接近1时clip也保持0。

这是有依据的机制解释，不是“此结构永远学不会”的定理。历史移除/替换末端压缩的受控对照没有恢复稳定求解收益，不能把LN2定为唯一根因。奖励/GAE/初始化/更新组织与该结构的交互仍可能影响能否离开弱响应区域。

## 3. 责任与研究结论边界

- **已确认事实**：当前公开结构在本项目训练实现和检查状态上有弱响应；优化器确实更新；网络三文件未被复制改坏；新train模式仍未消除问题。
- **得到支持的机制**：候选表示经过多阶段压缩、末端归一化削弱局部差异、共同logit平移不能产生动作偏好。
- **仍待验证的归因**：是公开结构的普遍可训练性问题、哪些初始化/奖励/GAE/更新组合造成长期停滞，还是作者实际使用了尚未对上的关键设置。没有证据给这些原因分配贡献比例。

4核/V100/断点续训不是目前已证实的根因；类似现象早在本次设备迁移之前和历史初始化权重中已出现。但这不等于排除所有设备/数值/随机流影响。不能用本次日志直接宣布论文错误，也不能把已记录的代码调整归咎于用户操作。

相对当前B0的MLP/BC收益仍是本地受控对照证据，但暂不能称“已击败作者论文对应的正式TGPPO模型”。新的结构在同样部分设置下可学习，有助于缩小排查范围；共同修复仍可能与不同结构交互，不能因此排除复现因素。

## 4. 最低成本的下一步补证（未执行）
