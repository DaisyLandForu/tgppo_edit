# 离线评分头对照：结果审计与下一阶段建议

日期：2026-11-02（北京时间）。四个 Custom 和 summarize 已由用户完成；本次只读核验与整理，不新增训练或 SCIP 求解，不覆盖原实验材料。本阶段整理完成，下一阶段尚未启动。

**结论：在本地 B0 ep100 的冻结表示和固定真实优势上，保留已训练中间层的原评分头经过 20 步仍无记录到的策略变化；直接线性头在两个来源种子均产生小幅响应，并改善固定批次 surrogate。这加强了“当前评分头映射抑制学习响应”的证据，但尚不能区分结构本身与已学中间层权重状态，也不能证明候选排序或求解性能改善。**

## 1. 已完成什么，实际花了多久

两种子各复用 256 个实际更新状态、164 个监测状态。上游 Transformer、BiMatching、树表示和 Critic 均冻结。两头最终标量读出共同归零，均使用 fresh Adam；原头其余层保留 ep100 权重。相同 batch 重复 20 步，非在线 PPO 续训。

| 作业 | 实际墙时 | 完成 head 步数 | 退出/封存 |
|---|---:|---:|---|
| original-s11 | 19.71 秒 | 20 | 0 / 核验通过 |
| linear-s11 | 10.34 秒 | 20 | 0 / 核验通过 |
| original-s22 | 14.45 秒 | 20 | 0 / 核验通过 |
| linear-s22 | 9.61 秒 | 20 | 0 / 核验通过 |
| 合计 | **54.12 秒** | **80** | 无未完成组 |

**这类 CPU 秒级至分钟级工作应直接本地执行。本次安排用户申请 Custom 的资源判断不当，增加了操作成本。** 后续在已授权范围内、现有环境可承载的短 CPU 离线实验默认本地运行；只有实际资源需求或用户明确要求时才转外部作业。此执行约定已记入 [AGENTS.md](../../../AGENTS.md)，不取消阶段验收或扩大训练/求解预算。

## 2. 两个种子的结果方向一致，但线性头改善很小

以下均为 step20 相对 step0。TV 是动作概率变化总量；surrogate loss 越低表示对这批固定优势目标拟合较好，不表示分支动作更优。

| 来源种子 | 评分头 | surrogate loss 变化 | 更新状态 TV 中位数 | 监测状态 TV 中位数 | 监测 TV > 1e-6 状态数 |
|---|---|---:|---:|---:|---:|
| 11 | 原头 | 0 | 0 | 0 | 0 / 164 |
| 11 | 线性头 | **−1.483e-5** | 5.811e-5 | 5.728e-5 | 140 / 164 |
| 22 | 原头 | 0 | 0 | 0 | 0 / 164 |
| 22 | 线性头 | **−9.704e-5** | 4.976e-4 | 1.795e-5 | 123 / 164 |

**E1：原头不仅末步不变，step0–20 的全部更新/监测 TV 记录均为 0；surrogate 没有改善。** 这是本轮统一归零读出和 FP32 执行条件下的记录，不是对原 B0 历史训练每一步或精确实数策略的断言。

**E1：线性头不只是“把输出变尖”，两个固定批次的 surrogate 也有所改善。** 但幅度仅 1e-5–1e-4，监测状态 TV 中位数仍仅 1e-5；整个 21 步曲线没有任何状态达到先前用于背景描述的 TV=0.01。这个阈值不是正确决策标准。尤其 s22 更新状态的 TV 明显大于监测状态，不能宣称获得训练分布之外的泛化。

164 个监测状态来自 17 个训练实例，不能当 164 个独立重复；两个来源训练种子也不能说成四个独立种子实验。实例级描述另存 [per_instance.csv](per_instance.csv)，不作显著性或 PDI 效果推断。

## 3. 更新执行正常，原头主要改变共同分数

| 原头证据（E1） | s11 | s22 |
|---|---:|---:|
| 34 个参数张量的 Adam step | 全部 20 | 全部 20 |
| 相对统一初始化改变的参数元素数 | 23,808 | 42,525 |
| 参数变化 L2 | 3.654e-3 | 1.684e-3 |
| 第 20 步更新的裁剪前梯度范数 | 3.394e-8 | 1.024e-8 |
| 末步监测共同 logit 平移绝对值中位数 | 3.043e-3 | 1.702e-3 |
| 末步监测去共同平移后 logit 变化 RMS 中位数 | 8.022e-11 | 3.611e-11 |

不能将本轮描述为“没有 optimizer.step”或“参数完全没动”。原头梯度远低于 0.5 的裁剪上限，四组各步 PPO clip_fraction 均为 0；原头未因达到 KL 边界而提前结束。**E2：softmax 对所有候选共同平移不敏感**，与这里“参数动了、策略未变”的事实吻合。

线性头末步梯度范数为 2.964e-4 / 2.077e-3，末步监测中心化 logit 变化 RMS 为 1.448e-4 / 4.459e-5；共同平移仍更大。不同参数化的总梯度范数不能直接当成公平的结构优劣指标，关键证据是固定目标与实际概率响应的配对结果。

## 4. 现在可以定位到哪里

| 判断 | 等级与边界 |
|---|---|
| 当前已训练原评分头是给定冻结表示上的学习响应瓶颈 | **E1 支持。** 原头 20 步无记录响应；同数据、同上游、同初始策略、同优化设置的线性头有小幅响应 |
| 上游表示完全相同、完全不含任何可拟合差异 | **E4 不支持此绝对说法。** 线性头能利用其中的差异改善固定批次目标；任务价值和充分性仍未知 |
| 只因历史 Adam 动量或未执行更新 | **E4 不能作为本轮全部解释。** 两头均 fresh Adam，原头参数确实更新后仍弱；不是对历史动量影响的完整排除 |
| 原头结构本身必然学不动，或唯一根因是 LN2 | **E3 未分离。** 原头中间层来自 ep100；替换整个头同时改变深度、门控、归一化和容量 |
| 只是本次复现把 Actor/modules 改错 | **E4 当前没有这项证据。** 本轮副本与保留原版的 actor.py、modules.py 逐字节相同；训练/奖励/协议差异仍需另行限定 |
| 作者权重也如此、论文已被否定 | **E3 未验证。** 目前是本地训练权重和缩预算协议，不是作者正式权重或论文完整协议 |
| 线性头已修好、现在可以全量重训 | **E4 证据不足。** 响应仍小，没有完整候选价值标签，也没有新增求解收益证据 |

当前优先级：**① 当前评分头的条件学习响应；② 原头中间层权重状态与结构的分离；③ 上游压缩及优势质量；④ 真正分支质量与 CPU/PDI 收益。** ③④并未被本轮排除，只是不应跳过②直接添加模块。

## 5. 下一阶段：本地做一次“原头中间层重置”对照

目的只回答：**原 TreeGate 架构在同一冻结表示上是否能学，还是 ep100 的中间层已进入很难响应的状态？** 当前对照的关键缺口是中间层训练历史。优先补这一项，不再建立 Custom 提交框架。

建议范围（未执行）：

- 原架构不变，在独立内存/输出副本中重新初始化整个评分头的线性层与 LayerNorm，再将最后标量读出归零；上游缓存完全复用。保持树门控、层数、宽度、PPO 目标、优化器、学习率和数据不变。
- 来源 checkpoint 种子 11/22，各用固定头初始化种子 101/202，共四个小运行；初始化种子和来源训练种子明确分开记录。参照本次原头与线性头结果，不重跑已完成组。
- 每个运行最多 20 个 head-only 更新，合计最多 80 步；单线程 CPU、本地串行，**整轮计算墙时上限 180 秒**。根据本轮实测，预计几十秒至两分钟；实际耗时以本地预算记录为准。
- 运行前确认配对初始均匀分布和行为 ratio；每步记录固定 surrogate 与 TV。非有限、输入漂移、平均训练 KL > 0.02、总墙时或步数到限即停止，不自动加步数、学习率或更换初始化种子。
- 预先以末步训练 surrogate 降低至少 1e-6 且更新状态 TV 中位数 > 1e-6 作为“可测条件学习响应”的工程筛查，固定报告全部步数及监测结果。它不是收益门槛，也不用于选 checkpoint。

| 对照结果 | 后续决策 |
|---|---|
| 两来源、两初始化均能响应 | 支持当前中间层权重状态是关键条件；先利用既有早晚 checkpoint 查退化进程，不能说原架构天生无效 |
| 重置后仍弱，而已测线性头能响应 | 加强当前表示上原头参数化/优化困难的证据；再选择一个最小结构改动，之后才讨论短在线验证 |
| 结果依赖来源或初始化，或触发停止 | 报告不稳定/未完成；不继续扩大随机种子搜索或全量训练 |

本轮及建议下一轮均无需 V100；不引入 HSTU，不改原基线，不新增 SCIP 求解。若后续要评价候选是否正确或 PDI 是否改善，必须另有可追溯标签或小预算真实求解，不能把本轮 surrogate/TV 替代这些证据。
