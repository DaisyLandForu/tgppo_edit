## 一个问题、原模型、一次受控更新

研究问题：当前原 B0 在同策略版本的保存轨迹上，用原 PPO 目标和 Adam 更新后，参数变化能否传导成可分辨的候选动作分布变化？

| 项目 | 拟冻结范围 |
|---|---|
| 起点 | B0-s11、B0-s22 各 ep100；只使用独立内存/目录副本 |
| 轨迹 | 紧随各 ep100 的 e100–103 完整保存轨迹；核验 policy_version、schema 和 SHA。无决策 episode 保持为空 |
| GAE | 在完整 episode 上按保存的 reward/value/done/bootstrap 重算；保持 episode 边界，先在完整同版本缓冲计算目标和原范围的优势标准化，再取 minibatch |
| minibatch | 每种子固定 RNG 的第一次原逻辑 minibatch，256 条真实 transition；索引在看更新后结果前冻结，不按优势、候选数或有利输出筛选 |
| 优化步上限 | 每种子最多 **1 次 Actor + 1 次 Critic optimizer.step**，两种子合计最多 4 次；只执行原更新循环的第一个逻辑 minibatch，随后停止 |
| 不变因素 | 原 Actor/Critic、H3 保存奖励、GAE、Adam 学习率及保存状态、熵项、PPO clip、梯度裁剪、Actor eval/Critic train 模式；不加入 LN2 变体 |
| 微批 | 沿用逻辑 batch=256、microbatch=16 的排序、padding trimming 和权重累计；不改变一次逻辑更新的定义 |
| 观测集合 | 更新前后在同一份 164 状态上测完整动作分布；这些状态仅用于诊断评估，**不替代同策略版本的 PPO 训练数据** |
| 计算 | CPU 单线程累计墙时≤600 秒，含导入、读取、检查、更新、汇总；超限即停，准确报告已完成步数。不用剩余时间追加 epoch、seed 或变体 |
| 禁止 | 新增 SCIP 求解、在线采样、完整 episode 训练任务、原基线覆盖、HSTU、奖励/结构搜索、V100 任务 |

该方案将原配置 n_epochs=3 的更新循环在第一个逻辑 minibatch 后截停，**不是一次完整历史 PPO update，也不是完整训练续接**。本轮先测一个真实更新步的局部响应；一次无响应不能证明更长训练永远无效。

## 更新前的硬性前置检查

1. 核验 checkpoint 的 actor、critic、两个 Adam 状态、配置和 policy_version。源码支持保存这些内容，但本方案不预先假定每个载荷兼容。优化器状态须恢复到 CPU；缺失时停止，不偷偷换成 fresh Adam。
2. 同版本轨迹按原语义导入；完整同版本缓冲不足 256 条则停止，不拼接其它策略版本、不截断 episode 后重算 GAE。
3. 对将使用的整个逻辑 minibatch 重算旧策略动作概率，更新前 ratio 最大偏差须≤原代码阈值 1e-4；不一致则停止并定位保存/加载/输入/版本问题。此前仅有首中末抽查通过，不能替代本轮全 batch 检查。
4. 固定随机状态和 batch 索引后再执行诊断仪表，避免额外前向改变 Critic dropout 或 batch RNG。历史在 GPU 上训练，本轮 CPU 重放不能声称跨设备逐位重现；恢复可用状态并记录差别，不初始化 CUDA。

## 每个阶段记录什么

- 更新前：原始/标准化优势分布、按来源 episode 的样本数、L=1 数量、旧策略一致性、完整候选分布、重复前向误差。
- 反向后、裁剪前后：Actor 各模块梯度范数、梯度裁剪比例、参数是否实际被优化器覆盖、Adam step/矩状态。
- optimizer.step 后：模块参数差、实际更新前后 ratio 分位数与 KL、PPO surrogate 与熵项、候选中心化 logit 变化、TV/熵/margin、最终分布相对均匀程度。另记录 Critic 损失和参数差；它不能作为 Actor 学会分支的证据。
- 完整性：原源码、原 checkpoint、轨迹和已封存交付文件哈希不变；新增参数只能存到新诊断目录。

这里使用真实优势加权的 PPO 目标；不会用任意正标签、score 梯度、温度缩放或共同 logit 平移代替学习响应。固定 164 状态的变化只能评估输出响应，没有专家动作或行动价值标签，不能判定分支排序正确。

## 预定判断与停止条件

| 观测 | 可以作出的判断 | 停止/后续动作 |
|---|---|---|
| policy 版本、旧概率、载荷或有限性检查失败 | 此次重放链条不可信 | 不更新；提交具体兼容性/复现问题，保留原基线 |
| 优势或梯度退化，或优化器没有覆盖预期参数 | 存在需要解释的学习信号/更新路径问题 | 提交证据；不借机加网络层 |
| 参数改变而分布变化落在重复数值误差内 | 在该单步条件下未测到可分辨的策略响应 | 如实报告，不称“训练永远无效”，不自动加步数 |
| 可分辨的候选偏好随真实更新改变 | 更新能够作用于动作分布 | 仅支持再提交单项短训练对照方案，不宣称 PDI 或泛化提升 |
| 任一预算、非有限、原文件漂移或异常退出 | 无法继续在本授权内可靠执行 | 截止并交付部分结果与明确缺口 |

不要求单步达到 TV=0.01 才算实验完成，不沿用该阈值充当“训练成功”。本轮以更新链条是否可核查、响应是否超过确定性重复误差为验收依据；正负结果均可交付。
