# 三时间点开发曲线：结果解读与下一步

本阶段已完成。**现有证据支持轻量MLP＋专家初始化作为可用方法候选；尚不支持PPO在其上带来跨训练种子稳定的求解收益，也不支持现在直接扩至300／500 episode。** 该判断不等于PPO全局无效或100 episode已经收敛。

本轮70/70有效：60模型＋10同机新relpscost，累计1371.782秒（22分51.8秒），低于2400秒上限；Silver4214、4个单线程CPU worker。没有新增训练、GPU或66测试集评估。源权重、冻结代码与已有结果保持不变。自动生成的[原始主表](REPORT.md)、[逐实例表](instances.csv)和[配对表](paired.csv)保持原样。

## 2. E1：全体均值受无Actor实例影响，不能简单说PPO越训越差

roi5alpha10n8在全部六模型、两个solver种子中均无Actor调用，均未证明完成。它的PDI在BC／PPO20／PPO100分别约11511.309／11564.963／11552.742；它虽只占五实例之一，却贡献约76%的全体PDI数值。

从BC到PPO100，全体平均PDI增加4.976，可分解为：共同Actor四实例贡献 **−3.311**，roi5alpha10n8贡献 **+8.287**。后者不能归因于神经动作。积分测量上下界只是截尾误差范围，并不覆盖系统负载引起的整个求解轨迹变化。

因此完整面板与共同Actor面板都保留：前者对应原开发指标，后者帮助核对神经决策参与；不能看到正反结果后删掉roi或更换主选模规则。

按运行前写下的“全5实例平均PDI最低、严格并列取早”规则，描述性最低点是种子11选BC-only、种子22选PPO100。两种子合并时BC-only最低。共同Actor面板的种子22最低点又在PPO20，说明目前没有统一、稳定的最佳PPO时长。未导出或替换任何原权重。

## 3. E1：仍不能宣称优于relpscost

PPO100相对原生的全体PDI仅低0.24%，但证明率60%对70%，平均optimize墙时高5.37%；共同Actor面板PDI低3.40%，证明率75%对87.5%，墙时高8.93%。五开发实例上的某一个均值领先，不构成全面胜过原生。

此前8个已查看探索实例上，MLP＋BC＋PPO100相对B0的PDI改善6.25%，实际Actor调用均摊耗时降低93.17%；相对原生PDI仍高44.00%。这些是[此前同轮配对结果](../continuation/RESULTS_REVIEW.md)，不是本轮70项新增发现；不将两个阶段的绝对时间合并。

本轮MLP Actor三个时间点均约1.68–1.70 ms/调用；PPO100为1.698 ms，特征提取约3.594 ms/调用。轻量结构的部署成本没有因继续训练而明显改变；提高episode数本身也不解决剩余求解差距。

## 4. E2：更新执行了；“没有稳定收益”不等于“没有训练”

既有训练日志显示MLP＋BC两个种子都完成25次有效PPO批更新，分别543／681次优化步；没有待更新的最终transition。重新计算初始重要性比率的最大偏差约2.86e−6／2.15e−6。实际权重发生变化，不能用本轮曲线接近平坦推断优化器未工作。

既有288个训练内部专家留出状态上，归一化专家NLL从BC的0.8331／0.8425变为PPO100后的0.8072／0.8196。它没有显示MLP整体丢失专家信号；NLL变好与求解PDI变好并不等价。上述状态参与过初始化选模，不是独立泛化测试。

本轮任务启动前已对BC格式包装做张量等值与原训练初始化指纹核验，对PPO20/100导出与完整checkpoint逐张量核验，并通过实际六模型CPU fork概率/动作一致性检查；最后重新校验源文件SHA。部署Critic耗时、策略fallback和CUDA初始化均为零。

## 5. E3：哪些解释仍没有证据

- 不能确认“只是训练太短，拉到500就能变好”；100 episode约覆盖20训练实例五遍，不是收敛证明。
- 不能确认“PPO遗忘专家”“奖励实现错误”“树信用分配就是原因”。当前日志和留出NLL不支持前一种简单解释，另外两种也没有因果验证。
- 本轮只核验MLP＋BC的三个时间点，不能把结论推广到SET／ISAB或所有PPO。
- 既有结构间CUDA初始流未完全一致是已知对照边界，不是此次同一MLP训练轨迹三个检查点之间的新混杂。今后新训练在独立副本修复并配对核验，原权重保持。

## 6. 建议：不扩大当前训练，下一轮只验证一种持续监督约束

当前轻量Actor结构和BC初始化已有真实结果，可以进入周五方法汇报。PPO部分应表述为“真实训练已完成，但相对BC-only的附加求解收益尚不稳定”。这比用更多episode替代收益证据更准确。

下一轮建议固定MLP和现有合法BC初始化，仅比较 **BC→原PPO** 与 **BC→PPO＋持续小权重专家监督**，两个训练种子共4个新Custom，仍先100 episode；BC-only保留为第三个必要参照。研究问题是持续监督能否约束有利于求解的策略/表示更新，不以“修复已证实遗忘”为理由。具体预算、验收和风险见[NEXT_STAGE_PLAN.md](NEXT_STAGE_PLAN.md)。这是方案，尚未实现或启动。

若当前只做周五汇报，可直接使用本轮与此前已完成的结构／BC结果，并展示PPO附加收益的边界。新候选必须在开发集PDI与证明率上成立，才值得扩大训练及冻结测试；不同时加入CL、改变奖励或树信用分配。
